# PublicPosts

Учебный проект для SkillFactory.

## Структура проекта

- `publicposts/` — Django backend
- `publicpostsapp/` — Django приложение
- `frontend/` — React frontend

## Запуск

### Backend

```sh
cd publicposts
python manage.py runserver
```

### Frontend

```sh
cd publicposts/frontend
npm install
npm start
```

## Домашние задания

Все задания выполнены.

## Реализовано

- Запрос типа DELETE на серверной стороне.
- Отправка DELETE-запроса на клиентской стороне.
- Визуальная реализация удаления в React-приложении.

- Опрос сервера на наличие новых записей.
- Реализованы пользовательские предпочтения в работе сервиса.
